## Установка

1. Установи Node.js 18 или новее.
2. Создай файл `.env` на основе `.env.example`.
3. Заполни `TOKEN` и `MONGO_URI`.
4. Выполни команды:

```bash
npm install
npm start
```

Slash-команды регистрируются автоматически при запуске `index.js`. Файл `deploy-commands.js` оставлен для ручной регистрации базовых `/all` и `/panel`, но обычно запускать его отдельно не требуется.

## Настройки Discord Developer Portal

В разделе **Bot** включи привилегированные намерения:

- Server Members Intent;
- Message Content Intent;
- Presence Intent.

При добавлении бота используй OAuth2 scopes:

- `bot`;
- `applications.commands`.

## Права бота

Для всех текущих модулей нужны:

- View Channels;
- Send Messages;
- Send Messages in Threads;
- Embed Links;
- Attach Files;
- Read Message History;
- Add Reactions;
- Manage Messages;
- Manage Channels;
- Manage Roles;
- Manage Threads;
- View Audit Log.

Administrator не обязателен. Роль бота должна находиться выше ролей, которые он выдаёт и снимает, включая роль «Гость», академию, каптур и тиры A/B/C.

## MongoDB

Бот использует MongoDB и базу `darknessbot`. Значение `MONGO_URI` должно указывать на доступный кластер. Не добавляй `.env` в GitHub.

## Проверка перед запуском

```bash
npm run check
```

Если какой-то старый модуль использует канал или роль, для которых пока не указан новый ID, его логика сохранена, но такую часть нужно будет отдельно привязать к новому серверу.
